# CashNote

Akıllı gelir ve gider takipçisi. React, TypeScript ve Tailwind CSS ile geliştirildi.

## Özellikler

- Gelir / gider **ekleme**, **listeleme**, **güncelleme**, **silme** (CRUD)
- Günlük, haftalık, aylık filtreleme
- Özet kartları ve tasarruf oranı
- Donut ve animasyonlu çubuk grafik
- Veriler LocalStorage'da saklanır

## Kullanılan Teknolojiler

React, TypeScript, Vite, Tailwind CSS

## Kurulum

    npm install
    npm run dev
